How does the selector choose?

The operating system determines which packages are available. The handheld model, GPU, and game guide the choice of fork. The CPU determines which Lichii Ally edition to use, and RAM helps put shared memory on handhelds in context.

Recommendations use release notes and downloads reviewed on November 8, 2026. Performance varies by game, driver, and hardware.

The selector checks GitHub for a newer release with the matching package. If the check fails or the file is unavailable, the download keeps its bundled version.
